# Mayur Mehta Design - Architectural Studio Frontend

Architecture, Interior Practice & Super Admin Platform Web Application.

- **Stack:** React 18, Vite, Vanilla CSS Design System, Lucide React Icons.
- **Branding & Identity:** Mayur Mehta Design luxury architectural palette (Architectural Taupe `#7B6F62`, Warm Sand `#FAF8F5`, Charcoal `#1E1A17`).
- **Features:** Multi-tenant Workspace Management, Role-Based Access Control, Project & Drawing Approvals, Master Catalog, Team & Seats Allocation, Offline Billing & GST Invoice Engine, Security Audit Logs.

---

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```
